1. Watch a heartbeat

You just wired the harness and opened the console; before trusting the bigger instruments, watch the simplest one respond to the simplest event.

01Watch a heartbeat
Context

Before trusting the instruments, see one instrument respond to one event. The heartbeat is the simplest: an O(1) timestamp written at the end of every agent turn.

You'll use
Claude Code heartbeat.sh obs-capture.sh
Do

Ask Claude Code anything at all - "list the files in this repo" is enough - and let the turn finish.

Underneath

The turn's end fires the Stop event. heartbeat.sh overwrites state/heartbeat.json, and obs-capture.sh appends the raw event to the out-of-repo record's spool. Telemetry fails open: if either hook broke, your turn would still complete.

Console
NOW the pulse dot turns live and the age resets to seconds.
