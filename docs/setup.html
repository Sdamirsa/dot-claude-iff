Step 2

Set it up

Requirements: bash, python3, git, and a browser. Nothing to install - no pip, no node.

On Windows: run the commands in Git Bash, and make python3 a python.org interpreter - not a uv-managed Python build (Windows 11 Smart App Control blocks those, and venvs built on them, as unsigned: astral-sh/uv#22869), and not the Microsoft Store stub. Either way the hooks never get to run. python3 .claude/tools/checkctl.py doctor checks both, in its smart_app_control and python3 rows.

Pick your path

SituationDo this
New / empty repoDownload dot-claude-iff-fresh.zip from the v0.3.0-beta.1 release (a pre-release: GitHub's "Latest" label still shows v0.2.2), unzip into the repo root, follow its START-HERE.md. Type its /adopt prompt yourself: typing the command is what lets the system's ritual run.
Existing repoDownload dot-claude-iff-adopt-kit.zip from the same release, unzip it anywhere outside your repo, open Claude Code in your repo, paste the one instruction from the kit's ADOPT.md. Your files are merged, never overwritten - a pre-existing .claude/ is the designed case.
Just exploringClone this repo; it runs on itself. Everything below works here directly.

Three switches, once

  1. Trust the hooks. On your first Claude Code session in the project it asks whether to run this project's hooks. Say yes - then prove it worked: 
    echo '{}' | bash .claude/hooks/heartbeat.sh
cat .claude/state/heartbeat.json   # a timestamp means the harness is alive
  2. Open the console. 
    python3 .claude/console/console.py
# prints your URL:  http://<folder>.localhost:<port>/console.html
    The port derives from the folder name (unless .claude/config/console.json pins one), so projects never fight over one default, and every session start prints the URL again. Give it half the screen, Claude Code the other half - terminal, VS Code and the desktop app all work the same. (The SessionStart hook auto-starts the server afterwards.) To move or delete the repo folder, run python3 .claude/tools/consolectl.py stop first.
  3. Tell it how you're billed (optional). If you use a Claude subscription, you are done: costs read "in plan". On API billing, set billing: "api" in .claude/config/model-prices.json and fill in your verified prices.
