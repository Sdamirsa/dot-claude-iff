3. Plan a real task

With a pointer in place, give the agent something real to resume into: a task file with a definition of done.

03Plan a real task
Context

A task file is a work block's skeleton: a goal with a definition of done, plan steps that each name their evidence, and a checkpoint a stranger could resume from.

You'll use
/plan-task tasks/
Do

In Claude Code, type /plan-task and describe something small and real from your project. Read the file it creates under .claude/tasks/ and notice every plan item's "done when".

Underneath

The skill instantiates tasks/_template.md, registers the task in STATUS.md, and sets the journal pointer. On resume, checkpoints are treated as claims to verify against disk, never facts - "reality wins" is the rule that makes stale checkpoints harmless.

Console
WORK your task appears with its status and next action.
